# Speech Assist for Android

Live speech recognition for people with speech impairments, in Kinyarwanda and English.
Text appears while you speak, and the app can read it aloud in a clear voice. Everything runs on the phone:
the app has no internet permission, and nothing you say is stored or sent.

**Website and live demo:** https://speech-assist.vercel.app

## Download

Get the latest APK from [Releases](https://github.com/maqamylee0/speech-assist-releases/releases/latest).

Requirements: Android 7.0 or newer, about 160 MB free space. Two files: `speech-assist-android-arm64.apk` for new phones (most phones) and `speech-assist-android-arm32.apk` for old phones (use it if the first will not install).

## Install

1. Download the file for your phone (new phones: `…-arm64.apk`; old phones: `…-arm32.apk`).
2. Open it. If Android asks, allow your browser or file manager to install unknown apps.
3. Open Speech Assist and allow the microphone.

Each release lists the APK's SHA-256 checksum, so you can check the download.

Speech Assist is a research prototype from the CDLI impaired-speech ASR project. It is not a medical device.
Kinyarwanda voice: C4IR Rwanda & KiNLP `kinya-flex-tts` (CC-BY-4.0). Open-source licences are listed in the app
(About → View licenses).
